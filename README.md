# [오름] 국어 · 성적 추이 리포트

학생 성적을 회차별로 쌓고, 학부모 상담용 A4 리포트를 뽑는 도구입니다.
의존성 없는 단일 HTML 파일이라 `index.html` 하나만 있으면 동작합니다.

## 쓰는 법

1. 배포된 주소를 크롬·엣지로 엽니다.
2. **설정 · 백업** 탭 → **백업 파일에서 복원** 으로 `.json` 백업 파일을 불러옵니다.
   (기기마다 한 번만 하면 그 브라우저에 계속 남습니다.)
3. **성적 입력** 탭에서 회차를 고르고 표에 바로 적습니다. 칸을 벗어나면 저장됩니다.
4. **개인 리포트** 탭에서 학생을 고르고 **인쇄 / PDF** 를 누르면 A4 한 장으로 나갑니다.

## 탭

| 탭 | 하는 일 |
|---|---|
| 성적 입력 | 회차별 점수·평균·석차 입력, 시트에서 붙여넣기로 가져오기 |
| 개인 리포트 | 점수 추이·영역별 득점·등급 추이·회차별 표·상담 코멘트 (A4 1장) |
| 반 전체 | 회차 분포, 회차별 평균 흐름, 많이 오른·내린 학생 |
| 학생 · 회차 | 명단과 시험 회차 관리 |
| 설정 · 백업 | 백업·복원, CSV 내보내기, 코멘트 프리셋, 구글 시트 동기화(선택) |

## 데이터가 어디 있는지

성적은 **그 브라우저 안에만** 저장됩니다(localStorage). 서버로 가지 않습니다.

- 주소가 다르면 저장소도 다릅니다. `localhost` 에서 넣은 값은 배포 주소에서 안 보입니다.
- 브라우저 기록을 지우면 사라집니다.
- **그래서 설정 · 백업 탭에서 주기적으로 `.json` 백업을 내려받아 두세요.** 그 파일이 유일한 사본입니다.

## 이 저장소에 학생 자료를 올리지 마세요

GitHub Pages 는 공개입니다. 이 저장소에는 **회차 틀과 코멘트 프리셋만** 들어 있고
학생 명단·성적·코멘트는 일부러 빼 두었습니다.

백업 `.json` 과 내보낸 `.csv` 는 `.gitignore` 로 막아 두었지만,
`git add -f` 같은 걸로 억지로 올리지는 마세요. 한 번 올라가면 커밋 기록에 남습니다.

## 인쇄

A4 세로, 여백 10mm 기준으로 맞춰 두었습니다.
개인 리포트 탭에서만 인쇄되고, 화면의 조작 부분은 종이에 나가지 않습니다.
상담 코멘트 중 **"시트에 적어 두신 메모"** 는 내부용이라 인쇄되지 않습니다.
